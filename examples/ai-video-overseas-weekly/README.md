# AI 视频出海周读示例

这是一次完整的模拟运行。所有圈友、文章、数据和链接均为虚构，仅用于展示输出结构。真实运行时，Skill 会用当前账号有权访问的 MCP 内容替换这些占位信息。

## 模拟用户提问

> 我刚开始做跨境电商，想尝试 AI 视频出海。请帮我找最近 7 天值得读的精华内容，告诉我圈友具体怎么做、哪些能借、这一周该验证什么。我要研究报告和朋友圈卡。

## 本次运行验证了什么

- “最近”按过去 7 天处理，且只选精华内容。
- 研究报告保留案例细节、短原话、结果、边界和原帖入口。
- 三篇材料被分成内容、工作流和成交验证三个主题，避免混成泛泛趋势。
- 朋友圈卡只写消化后的内容和阅读体会，不显示作者、文章或来源。
- 三张卡分别服务总判断、内容与流程、这一周的验证动作，避免一张图塞满所有信息。
