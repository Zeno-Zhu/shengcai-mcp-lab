# 生财 MCP 研究方法

## 1. 来源与用途

| 来源 | 在系统中的角色 | 典型使用 |
| --- | --- | --- |
| 风向标 | 早期雷达 | 找变化、异常与待验证机会 |
| 精华帖 | 方法教材 | 拆商业闭环与可迁移变量 |
| 中标帖 | 代表性实践 | 交叉验证优秀操作样本 |
| 日常帖/朋友圈 | 社交现场 | 找真实实践者、问题与连接线索 |
| 项目库 | 候选项目 | 比较案例、进度与可进入性 |
| 航海 | 实战训练场 | 看报名、地图、手册、问答、作业与产出，推进当前任务 |
| 深海圈 | 垂直学习场 | 查圈内内容、课程、章节与学习进度，围绕主题深挖 |
| 活动/课程 | 技能 SOP | 补能力、查课程、找到同频人 |
| 评论/问答 | 反例与约束 | 找被忽略的前提和争议 |
| 个人足迹/输出 | 个人记忆 | 避免重复阅读，沉淀判断 |

## 2. 三层分类

先由 AI 标记，再由用户只决定状态。

| 维度 | 取值 | 判断问题 |
| --- | --- | --- |
| 决策角色 | 信号 / 模型 / 认知 | 它告诉我变化、闭环，还是机制？ |
| 与我距离 | 内部 / 边缘 / 外部 | 我现在能做、补一点能做，还是暂不具备？ |
| 时效 | 紧急 / 本周 / 耐久 | 现在不处理会不会失效？ |
| 人工状态 | 线索 / 课题 / 动作 | 它是否会进入研究或改变我本周行为？ |

默认把“数据是真的”与“路径可走通”分开：先保留线索，再找独立证据。单帖数据、截图、叙述只能构成弱证据。

## 3. 主线、邻近与拓展

方向卡不是信息围墙。每条材料还要按与用户的关系进入三条通道：

| 通道 | 含义 | 默认处理 |
| --- | --- | --- |
| 主线 | 直接服务当前方向、课题或实验 | 可以进入本周动作 |
| 邻近 | 复用同一能力、用户、平台或商业环节 | 放入课题或能力补强 |
| 拓展 | 不匹配当前方向，但可能改变机会判断 | 仅作为“值得跨界阅读” |

拓展内容必须同时通过三道门，才可进入日报或周报的一席：

1. **机制可迁移**：能说清它迁移到用户身上的一条机制，例如获客、留存、分发、定价、交付或自动化，不能只因“很火”。
2. **证据足够**：至少有一个具体结果、官方变化或两个独立案例；单一夸张叙述只能观察。
3. **判断增量**：它能让用户看到新的客户、收入模型、能力杠杆或风险，而不只是增加待办。

用简分判断是否入选：个人相关 0–3、机制可迁移 0–3、证据 0–3、判断增量 0–2、切换成本 -2–0。主线或邻近通常总分 ≥6；拓展还必须“机制 ≥2、证据 ≥2”。日报最多保留 1 条拓展信号，周报最多 2 条；它们默认标为“阅读 / 观察”，只有用户主动升级才进入课题或动作。

## 4. 优先级与停止规则

一个内容值得进入周报，通常同时满足三项以上：与方向卡高度相关、存在可验证变化、至少有一个可迁移变量、与用户能力距离较近、能在 7–14 天内低成本测试。热度仅作参考。

停止信息输入并转去行动的信号：连续 3 天没有改变判断，或一周没有产生新的实验/判断更新。日常不是每天都必须写；没有变化时如实写“无新增信号”。

## 5. 3–14–90 节奏

- 3：出现至少 3 个相对独立案例后，才把零散信号升级成课题。
- 14：为课题安排 14 天内可完成的低成本测试。
- 90：除非平台规则变化或出现可验证失败，给方向约 90 天积累与复盘窗口。

## 6. 报告骨架

### 赛道研究

赛道研究不使用普通报告骨架压缩材料。先按 `track-research.md` 建立检索记录、A/B/C 索引和 A/B 级单篇资料，再生成观点、业务案例、工作流、共识分歧与趋势研究。快速速查也要保留单篇资料入口，不能只交一页总结。

### 昨日雷达

1. 一句结论
2. 3–5 张信号卡：来源、证据、相关性、状态、下一步
3. 五维雷达：需求、供给、分发、变现、风险
4. 今晚一个动作
5. 至多一条“拓展信号”：为什么值得跨界阅读、可迁移机制、为何暂不行动

### 本周研判

1. 本周判断有没有更新
2. 主题簇与交叉证据
3. 反例、未知项、需要补的能力
4. 唯一优先实验 / 明确停止项
5. 下周验证指标
6. 至多两条“拓展阅读”：只说明新判断，不制造新项目

### 单篇拆解

事实摘要 → 商业闭环 → 证据和假设 → 可迁移变量 → 风险/反例 → 对方向卡的含义 → 下一步。

### 深海圈导航

1. 已加入圈与用户课题的匹配度
2. 圈内主题、课程与章节地图
3. 已学/未学、正在卡住的位置
4. 一条最值得读的内容或一个章节
5. 一个练习、输出或提问动作

### 航海作战台

1. 已报名航海、目标与当前进度
2. 当前任务、已提交作业与反馈
3. 手册、问答与领航内容中的相关帮助
4. 一个卡点和最小下一步
5. 周内完成证据

## 7. 圈友链接原则

优先找比用户高半步的人：方向相邻、已有公开实践、能围绕具体问题互动。先公开提供小价值或展示自己的行动/数据，再提一个窄问题。连接的目标是共同推进课题，不是索取资源。

## 8. AI 顾问提问模板

### AI 亦仁

“我是[阶段]，方向是[方向]。以下是来自[来源]的[案例数]条材料：[摘要]。请从项目机会、商业闭环、长期积累与社区连接四个角度，指出最值得验证的一项和最容易误判的前提；给出一个 [时间] 内的行动建议。”

### AI 刘小排

“我的当前判断是：[判断]。证据是：[摘要]。请用反证方式检查我的盲点，判断它应是线索、课题还是动作；给一个今晚可完成的最小动作，以及什么反馈会让我停止或更新判断。”
